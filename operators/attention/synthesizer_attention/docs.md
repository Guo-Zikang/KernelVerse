# synthesizer_attention

## Function

Computes dense Synthesizer attention where attention logits are generated by an MLP from the input tokens instead of by query-key dot products.

## Inputs

- `tensor`: input tensor with shape `[batch_size, seq_len, num_heads * head_dim]`.

All input tensors use the dtype selected by the shape entry.

## Output

- Tensor with shape `[batch_size, seq_len, num_heads * head_dim]`.
- Output dtype must match the configured shape dtype.

## Implementation Notes

- The reference projects values with `w_v`.
- It generates attention logits with `synth_fc1`, ReLU, and `synth_fc2`.
- `synth_fc2` produces `num_heads * seq_len` logits for every query token; reshape this to `[batch_size, num_heads, seq_len, seq_len]`.
- Apply softmax over the key dimension, multiply by the value tensor, then apply the output projection `w_o`.
- This is not dot-product attention: do not compute QK scores for the core attention weights.
- Do not call PyTorch attention, matmul, softmax, linear, ReLU, reshape/permutation, or other PyTorch operators for the core computation in `ModelNew.forward`.

## Precision Notes

- For FP16/BF16 inputs, compute synthetic logits, softmax max/sum, probability-value accumulation, and output projection accumulation in FP32, then cast only the final output.
